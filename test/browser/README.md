# Браузерные тесты панели

`panel.html` — это 1600 строк разметки, стилей и логики, которых компилятор Go
не видит. Всё, что здесь ломалось за время работы, ломалось молча: удалённая
функция, вырезанный блок, правило CSS, обнулившее отступы. Эти тесты — то, что
такое ловит.

## Запуск

```
npm install          # один раз
npm test             # против локального mor
MOR_URL=https://адрес:9090 MOR_PASSWORD=пароль npm test
```

По умолчанию берётся `https://127.0.0.1:9090`. Самоподписанный сертификат
принимается: тесты проверяют панель, а не удостоверяющий центр.
