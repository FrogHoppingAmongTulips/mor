# mor

Свой VPN на своём сервере. Четыре протокола сразу, одна ссылка на всех, управление
из терминала или из браузера.

## Установка

```
curl -fsSL https://github.com/FrogHoppingAmongTulips/mor/releases/latest/download/install.sh | bash
```

Ubuntu, Debian и родственники. Ставит движки, открывает порты, настраивает себя сам.
Дальше набери `mor` — меню, всё цифрами.

## Обновление

```
mor update
```

## Удаление

```
curl -fsSL https://github.com/FrogHoppingAmongTulips/mor/releases/latest/download/install.sh | bash -s uninstall
```

Сносит mor, движки и все ключи.

---

## Как это работает

Создаёшь ключ — получаешь одну ссылку. Внутри неё все протоколы сервера сразу.
Приложение открывает её и само берёт тот, что работает в этой сети: заблокировали
Reality — переключилось на Hysteria2, человек ничего не заметил.

Добавил протокол на сервере — он появился у всех. Сменил порт — ссылки обновились
сами, раздавать заново не нужно.

## Протоколы

| | Транспорт | Когда нужен |
|---|---|---|
| **Hysteria2** | UDP | самый быстрый |
| **VLESS+Reality** | TCP | понимают почти все приложения, проходит там, где режут остальное |
| **VLESS Encryption** | TCP | новое шифрование Xray, без сертификатов — есть не в каждом клиенте |
| **Shadowsocks** | TCP | работает даже в самых старых приложениях |

Все четыре работают одновременно, лишний выключается: `mor proto off ss`
(`hy2`, `reality`, `enc`, `ss`). Второго движка ни один не требует.

## Работает в любом приложении

Приложения не договорились об одном формате. Одна и та же ссылка отдаёт три —
mor смотрит, как приложение представилось, и отвечает тем, что оно понимает.

| Формат | Кто читает |
|---|---|
| список ссылок | v2rayN, v2rayNG, Nekobox, Streisand, Shadowrocket, Happ |
| Clash YAML | Clash Meta, mihomo, Stash, Verge |
| sing-box JSON | sing-box, SFI/SFA/SFM, Karing, Hiddify |

Если приложение представилось невнятно, формат можно назвать прямо, дописав к ссылке
`/clash`, `/singbox` или `/raw`.

VLESS Encryption попадает только в список ссылок — его понимают пока лишь клиенты на
Xray. В Clash и sing-box он не кладётся намеренно: одна непонятная строка роняет
разбор всего профиля, и человек остался бы вообще без протоколов вместо трёх рабочих.

Ключ передаётся как угодно — QR-кодом, ссылкой или файлом конфигурации. Это одни и
те же данные в трёх видах.

## Ограничения

Срок и объём, оба необязательные, пишутся одной строкой в любом порядке:

```
mor limit 1 30d 10gb
mor limit 1 off
```

Срок: `30min`, `12h`, `5d`, `3m`, `1y`. Объём: `500mb`, `10gb`, `1.5tb`; голое число —
гигабайты. `10m` — это десять месяцев, мегабайты пишутся `10mb`.

Трафик считается по всем протоколам человека вместе: переключиться на другой протокол
и получить лимит второй раз нельзя. Когда ограничение сработает, ключ перестаёт
пускать сам и остаётся в списке с пометкой. Снял ограничение — снова работает, ничего
раздавать заново не надо.

**Сброс раз в месяц** включается в панели: первого числа счётчик обнуляется сам, и
месячная норма начинается заново. Сервер, выключенный первого числа, досчитает сброс,
когда вернётся.

**Лимит устройств** — сколько человек может пользоваться ключом одновременно. Ставится
в панели, защищает от ключа, разошедшегося по десятку людей. Работает только на
Hysteria2: остальные три протокола не сообщают о подключениях, считать там нечего.
Переподключение своего же устройства слот не занимает.

## Веб-панель

```
mor panel password ПАРОЛЬ
```

Дальше `https://адрес-сервера:9090`. Сертификат mor получает сам при установке —
Let's Encrypt умеет выдавать их на голый IP, домен не нужен, продление
автоматическое. Если выпустить не удалось (занят порт 80, нет сети), панель
работает на собственном сертификате: браузер один раз предупредит, но пароль
и ключи по сети открытым текстом не пойдут. Перевыпустить или перевести на
домен — `mor panel cert <домен или ip>`. Порт — `mor panel port N`, выключить — `mor panel off`.

Один экран, плитки. Открываешь плитку — она остаётся открытой справа.

| Плитка | Что внутри |
|---|---|
| **Ключи** | список, кто в сети, создание, срок и лимит, QR, ссылка на каждый протокол |
| **Статус** | работает или нет, какие протоколы слушают и на каких портах |
| **Система** | CPU и память за сутки, свободное место, что занимает диск |
| **Трафик за месяц** | сколько прошло и кто израсходовал больше |
| **Перезапуск** | поднять движки заново |
| **Последние действия** | что менял администратор и когда |
| **Настройки** | протоколы, DNS, пароль панели, порты и маскировка |

Срок и лимит меняются без пересоздания ключа — ссылка остаётся прежней.

Русский и английский, тёмная и светлая тема.

### Что панель не собирает

«Сейчас в сети» показывает только сам факт подключения. Ни адреса клиента, ни куда он
ходит, mor не записывает нигде — VPN существует ровно затем, чтобы этих данных не было.
Единственный журнал — действия администратора.

Вход в панель ограничен по числу попыток: единственный пароль, доступный из интернета,
иначе перебирался бы бесконечно. Сессия переживает перезапуск mor — обновление сервера
не стоит логина.

Панель отдаётся только по HTTPS: заход по `http://` переадресуется, а браузеру
запрещено встраивать её в чужую страницу и брать что-либо со сторонних адресов.
Сам mor работает с урезанными правами — файловая система для него только на чтение,
кроме своих каталогов.

`GET /healthz` отвечает без пароля — для внешнего мониторинга. Он говорит только
«работает» или «нет», и ничего больше.

## Проверка

Сервер не видит себя со стороны: изнутри порт всегда выглядит открытым. `mor check`
просит чужие узлы в разных странах постучаться в каждый порт снаружи — это занимает
около минуты.

Если что-то не так, mor говорит что именно и предлагает **«Исправить»**. Само чинится:
остановленный движок, отпущенный порт, закрытые в firewall порты, разъехавшиеся часы,
упавшая раздача ссылок, переставший отвечать DNS. Порт, который режут по дороге,
перезапуском не лечится — там mor подбирает другой.

`mor check --fast` отвечает мгновенно и только про эту машину.

## Команды

```
mor user телефон              ключ на всех протоколах, одна ссылка
mor user --reality ноут       только один протокол (--hy2, --enc, --ss)
mor list                      все ключи
mor qr 1                      показать ключ ещё раз
mor del 1                     удалить
mor limit 1 30d 10gb          срок и объём (off — снять)

mor proto                     что работает
mor proto off ss              выключить протокол
mor port 2096                 порт Hysteria2
mor dns 9.9.9.9               резолвер для клиентов
mor sni www.apple.com         сайт-прикрытие
mor host vpn.example.com      адрес в ссылках

mor panel password ПАРОЛЬ     включить веб-панель
mor panel cert <домен|ip>     выпустить сертификат заново
mor status                    состояние сервера
mor check                     доходят ли порты снаружи
mor update                    свежая версия
```

## Переезд на другой сервер

Скопируй `/etc/mor` на новую машину, поставь mor там и укажи прежний адрес
(`mor host`). Ключи, сроки и расход переедут вместе с файлом — выданные ссылки
продолжат работать.

## Архитектура

```
cmd/mor           меню, команды, демон, веб-панель
internal/config   настройки и ключи сервера (config.json)
internal/store    ключи клиентов (users.json)
internal/proxy    описание точки подключения и её вид для каждого приложения
internal/sub      раздача подписок
internal/hysteria Hysteria2: сертификат, конфиг, коллбэк авторизации
internal/xray     Reality, Encryption, Shadowsocks: конфиг и ключи на лету
internal/stats    расход трафика (stats.json)
internal/webauth  пароль и сессии панели
internal/auditlog журнал действий администратора
internal/sysinfo  загрузка сервера
internal/systemd  перезапуск движков
internal/probe    внешняя проверка портов
internal/qr       QR в терминале
```

Единственная зависимость — `github.com/skip2/go-qrcode`, остальное на стандартной
библиотеке.

Hysteria2 спрашивает разрешение на каждое подключение у коллбэка mor на
`127.0.0.1:9797` — поэтому её ключи применяются без перезапуска, а истёкшие отсекаются
в ту же секунду. У Xray для этого есть локальный порт управления: ключи добавляются и
удаляются на лету, живые соединения не рвутся. Через него же читается расход трафика —
счётчики движков обнуляются при перезапуске, поэтому копит их mor.
