# mor

VPN на своём сервере. Четыре протокола, одна ссылка на все, управление из терминала
или из браузера.

Требуется Ubuntu, Debian или производный дистрибутив.

## Установка

```
curl -fsSL https://github.com/FrogHoppingAmongTulips/mor/releases/latest/download/install.sh | bash
```

## Обновление

```
mor update
```

## Удаление

```
curl -fsSL https://github.com/FrogHoppingAmongTulips/mor/releases/latest/download/install.sh | bash -s uninstall
```

Удаляет mor, движки и все ключи.

---

## Как это работает

Ключ — одна ссылка, в которой лежат все протоколы сервера. Приложение читает её и
подключается тем протоколом, который работает в текущей сети; если он перестал
проходить, переключается на другой.

Ссылка не меняется при изменениях на сервере: добавленный протокол появляется у всех
ключей, смена порта подхватывается при следующем чтении. Раздавать заново не нужно.

## Протоколы

| | Транспорт | Когда нужен |
|---|---|---|
| **Hysteria2** | UDP | самый быстрый |
| **VLESS+Reality** | TCP | поддержан почти везде, проходит там, где блокируют остальное |
| **VLESS Encryption** | TCP | шифрование Xray без сертификатов, поддержан не всеми клиентами |
| **Shadowsocks** | TCP | работает в старых приложениях |

Работают одновременно, любой выключается: `mor proto off ss` (`hy2`, `reality`,
`enc`, `ss`).

## Форматы подписки

Клиенты используют разные форматы. mor определяет формат по User-Agent и отдаёт
подходящий.

| Формат | Клиенты |
|---|---|
| список ссылок | v2rayN, v2rayNG, Nekobox, Streisand, Shadowrocket, Happ |
| Clash YAML | Clash Meta, mihomo, Stash, Verge |
| sing-box JSON | sing-box, SFI/SFA/SFM, Karing, Hiddify |

Формат задаётся явно суффиксом `/clash`, `/singbox` или `/raw`.

VLESS Encryption отдаётся только в списке ссылок: его поддерживают лишь клиенты на
Xray, а нераспознанная строка в профиле Clash или sing-box ломает разбор всего файла.

Подписка отдаётся по HTTPS, если у панели есть сертификат от центра сертификации
(`mor panel cert`). С самоподписанным остаётся http: клиенты такой сертификат не
принимают. Порт отвечает на оба протокола, ранее выданные ссылки работают — на
http-запрос приходит переадресация.

## Ограничения

Срок и объём, оба необязательные, в любом порядке:

```
mor limit 1 30d 10gb
mor limit 1 off
```

Срок: `30min`, `12h`, `5d`, `3m`, `1y`. Объём: `500mb`, `10gb`, `1.5tb`; голое число —
гигабайты. `10m` — десять месяцев, мегабайты пишутся `10mb`.

Трафик суммируется по всем протоколам ключа, поэтому переключение протокола не даёт
второй лимит. При срабатывании ограничения ключ перестаёт пускать и остаётся в списке
с пометкой; после снятия работает снова, ссылка не меняется.

**Сброс раз в месяц** включается в панели: первого числа счётчик обнуляется. Если
сервер был выключен первого числа, сброс выполняется при следующем запуске.

**Лимит устройств** задаётся в панели и проверяется в двух местах. Hysteria2
запрашивает разрешение на каждое подключение. Для остальных трёх протоколов данных о
подключениях нет, поэтому лимит применяется при выдаче подписки — по заголовку
`x-hwid`, который присылают не все клиенты; клиент без него пропускается.
Переподключение известного устройства слот не занимает. Кнопка со счётчиком в
карточке ключа сбрасывает список устройств.

## Веб-панель

```
mor panel password ПАРОЛЬ
```

Дальше `https://адрес-сервера:9090`. Сертификат выпускается при установке: Let's
Encrypt выдаёт сертификаты на IP-адрес, домен не нужен, продление автоматическое.
Если выпуск не удался (занят порт 80, нет сети), используется самоподписанный —
браузер предупредит один раз, трафик при этом шифруется. Перевыпуск и переход на
домен — `mor panel cert <домен или ip>`. Порт — `mor panel port N`, выключение —
`mor panel off`.

| Плитка | Содержимое |
|---|---|
| **Ключи** | список, кто в сети, создание, срок и лимит, QR, ссылка на каждый протокол |
| **Статус** | состояние движков, какие протоколы слушают и на каких портах |
| **Система** | CPU и память за сутки, свободное место, что занимает диск |
| **Трафик за месяц** | объём и распределение по ключам |
| **Перезапуск** | перезапуск движков |
| **Последние действия** | журнал действий администратора |
| **Настройки** | протоколы, DNS, пароль панели, порты, маскировка |

Срок и лимит меняются без пересоздания ключа, ссылка остаётся прежней.

Русский и английский, тёмная и светлая тема, вёрстка под телефон.

### Что не записывается

«Сейчас в сети» показывает только факт подключения. Адреса клиентов и посещаемые ими
ресурсы не записываются нигде. Единственный журнал — действия администратора.

Число попыток входа ограничено. Сессия сохраняется на диск и переживает перезапуск
mor.

Панель работает только по HTTPS, запрос по `http://` переадресуется. Заданы CSP,
X-Frame-Options и HSTS: страницу нельзя встроить в чужую и нельзя загрузить в неё
что-либо со сторонних адресов. Служба systemd работает с ограниченными правами,
файловая система доступна на запись только в каталогах mor.

`GET /healthz` отвечает без пароля и сообщает только состояние службы — для внешнего
мониторинга.

## Проверка портов

Изнутри порт всегда выглядит открытым, поэтому `mor check` проверяет доступность
через внешние узлы в разных странах. Занимает около минуты.

При обнаружении проблемы mor называет её и предлагает **«Исправить»**. Устраняются
автоматически: остановленный движок, освободившийся порт, закрытые в firewall порты,
расхождение часов, упавшая раздача подписок, неотвечающий DNS. Порт, блокируемый по
пути, перезапуском не восстанавливается — для него подбирается другой.

`mor check --fast` проверяет только эту машину и отвечает сразу.

## Команды

```
mor user телефон              ключ на всех протоколах, одна ссылка
mor user --reality ноут       только один протокол (--hy2, --enc, --ss)
mor list                      все ключи
mor qr 1                      показать ключ ещё раз
mor del 1                     удалить
mor limit 1 30d 10gb          срок и объём (off — снять)

mor proto                     что работает
mor proto off ss              выключить протокол
mor port 2096                 порт Hysteria2
mor dns 9.9.9.9               резолвер для клиентов
mor sni www.apple.com         сайт-прикрытие
mor host vpn.example.com      адрес в ссылках

mor panel password ПАРОЛЬ     включить веб-панель
mor panel cert <домен|ip>     выпустить сертификат заново
mor token new <имя>           ключ для API
mor status                    состояние сервера
mor check                     доходят ли порты снаружи
mor update                    свежая версия
```

## API

Всё, что делает панель, доступно программно:

```
mor token new бот
curl -H 'Authorization: Bearer mor_…' https://адрес:9090/api/users
```

Описание маршрутов — [docs/api.md](docs/api.md).

## Терминал и панель

Работают над одними файлами. Ключ, созданный командой `mor user`, появляется в панели;
созданный в панели — в `mor list`. Настройки, изменённые в терминале, панель
подхватывает в течение минуты и не затирает при сохранении.

## Переезд на другой сервер

Скопировать `/etc/mor` на новую машину, установить mor и указать прежний адрес
(`mor host`). Ключи, сроки и расход трафика переносятся вместе с каталогом, выданные
ссылки продолжают работать.

## Архитектура

```
cmd/mor           меню, команды, демон, веб-панель
internal/config   настройки и ключи сервера (config.json)
internal/store    ключи клиентов (users.json)
internal/proxy    описание точки подключения и её вид для каждого приложения
internal/sub      раздача подписок
internal/tlsx     TLS и http на одном порту
internal/hysteria Hysteria2: сертификат, конфиг, коллбэк авторизации
internal/xray     Reality, Encryption, Shadowsocks: конфиг и ключи на лету
internal/stats    расход трафика (stats.json)
internal/webauth  пароль, сессии и токены панели
internal/auditlog журнал действий администратора
internal/sysinfo  загрузка сервера
internal/systemd  перезапуск движков
internal/probe    внешняя проверка портов
internal/qr       QR в терминале
```

Единственная зависимость — `github.com/skip2/go-qrcode`, остальное на стандартной
библиотеке.

Hysteria2 запрашивает разрешение на каждое подключение у коллбэка mor на
`127.0.0.1:9797`, поэтому её ключи применяются без перезапуска, а истёкшие
отклоняются сразу. Xray управляется через локальный порт API: ключи добавляются и
удаляются на лету, существующие соединения не рвутся. Через него же читается расход
трафика — счётчики движков обнуляются при перезапуске, поэтому итог хранит mor.
